# Sonika — Beauty & Accessories

A responsive storefront and admin dashboard for a small cosmetics and accessories shop selling makeup, churo, dhago, hair accessories and more.

## Stack
- Frontend: React + Vite + Tailwind CSS
- Backend: Django + Django REST Framework + JWT authentication
- Database: PostgreSQL in production (SQLite for local quick-start)
- Images: ImageKit signed direct uploads
- Hosting: Vercel frontend, Render backend

## Included
- Responsive home, product catalogue, product details, About, Contact and FAQ pages
- Product and category management
- Admin login and dashboard
- Editable shop address, Google Maps embed, phone, WhatsApp and opening hours
- Editable About content and FAQs
- ImageKit product-image upload
- Render Blueprint and Vercel configuration

See docs/SETUP.md for local development and deployment. Never commit credentials or environment files.
