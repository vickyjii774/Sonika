# Sonika — Cosmetics & Accessories Shop

A responsive storefront and private admin dashboard for a small cosmetics and accessories shop.

## Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Django + Django REST Framework
- Database: PostgreSQL
- Images: ImageKit direct uploads
- Hosting: Vercel (frontend), Render (backend)

## Project status
Initial application scaffold is being added. See `docs/SETUP.md` for local setup and deployment instructions.
